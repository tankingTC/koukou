# koukou Android 布局与样式规范  v2.0

适用对象：koukou IM（仿 QQ 风格即时通讯练手项目，包名 com.example.koukou）。
本规范与下列文件双向对齐，任何尺寸/颜色变更应同步修改本文件以避免漂移：
  - 尺寸 token： app/src/main/res/values/dimens.xml + values-sw600dp/dimens.xml
  - 主题契约： app/src/main/java/com/example/koukou/theme/ThemePalette.java
  - 性能铁律： 扩展.md  §9.5

变更历史：
  v1.0  2026-04  初版（基于 Aura 助手 app 设计稿，与 koukou 实际页面部分脱节）
  v2.0  2026-05  完全对齐 koukou 当前实现；引入 dimens token、ThemePalette、登录历史模式、
                 Snackbar+内联错误规范、动效预算、性能铁律、可访问性约束。

================================================================================
0. 总则 — 三条铁律
================================================================================

铁律 1： **dp 数值必须引用 @dimen/ token，禁止裸 dp**
  禁止 ✗  android:layout_margin="20dp"
  允许 ✓  android:layout_margin="@dimen/space_md"
  例外    装饰艺术资产（如 view_iridescent_butterfly.xml 蝴蝶光翼），按设计稿摆放豁免。

铁律 2： **颜色必须用 ThemePalette 字段或 palette 驱动的 drawable，禁止硬编码 #RRGGBB**
  禁止 ✗  android:textColor="#FFFFFF"
  允许 ✓  textView.setTextColor(palette.textPrimary)
  XML 中可保留 @color/butterfly_text_primary 作为初始展示态，
  但 observeAppearance 必须用 palette 覆盖，否则切到浅色主题会"白底白字"。

铁律 3： **间距严格遵循 8dp 网格，组件内部尺寸可豁免但必须走 token**
  a) 间距（layout_margin* / padding*，元素之间的留白）严格 8dp 网格：
        允许    4 / 8 / 16 / 24 / 32 / 48 dp（即 space_xs..space_xxl）
        禁止    3 / 6 / 10 / 14 / 18 / 22 / 28 / 36 dp 等裸"半步"值
  b) 组件内部构件（圆角、icon 尺寸、badge 尺寸等）不受网格约束，
     但**必须通过 dimens.xml token 声明**，禁止散布裸 dp：
        合规 ✓   input_corner_radius=12dp、bubble_padding=12dp、
                 button_secondary_corner=20dp、bubble_corner=20dp、
                 icon_sm=16dp、badge_min_size=20dp
        违规 ✗   XML 里直接写 android:layout_width="22dp"
  c) 装饰艺术资产（view_iridescent_butterfly 等）完全豁免网格与 token 要求。
  历史     迁移前布局存在 200+ 处 10/14/18/22/28dp，已全部消除。

2. 主题系统 ThemePalette
================================================================================

源： app/src/main/java/com/example/koukou/theme/ThemePalette.java
内置 8 主题（chatBackground 字符串）：
  butterfly       蝴蝶流光（默认，深色）
  minimal         极简（深色）
  minimal_white   极简（浅色）
  pink_bunny      粉兔（浅色）
  matrix          黑客代码雨（深色）
  stardust        星尘（深色）
  cyber           电子（深色）
  raindrop        雨滴（深色）

2.1 palette 字段总览

  ┌─ 文字 ────────────────────────────────────────────────
  │ textPrimary      主标题、条目名、昵称
  │ textSecondary    副文本、签名、最后一条消息、空态
  │ textTertiary     时间、弱化说明、提示
  │ textAccent       账号、强调字段
  ├─ 图标 ────────────────────────────────────────────────
  │ iconPrimary      工具栏图标、返回键
  │ iconAccent       设置项强调图标
  │ iconMuted        次级图标
  ├─ 线条 ────────────────────────────────────────────────
  │ cardStroke       卡片描边、输入框 stroke
  ├─ 背景资源 (DrawableRes) ──────────────────────────────
  │ bgGlassCard           大型信息卡片（个人资料、登录卡）
  │ bgListCard            列表条目（会话、联系人）
  │ bgSettingsRow         设置项行
  │ bgSettingsActionRow   设置项危险/退出行
  │ bgPanel               小型按钮/图标面板（返回键、添加好友）
  │ bgBottomNav           底部导航条
  │ bgUnreadBadge         未读红点
  │ bgInputBar            聊天输入条（常态）
  │ bgInputBarActive      聊天输入条（输入激活）
  ├─ 控件 ────────────────────────────────────────────────
  │ switchOffTrack/Thumb  Switch 关闭态轨道/滑块
  │ switchActiveAlpha     Switch 激活态轨道 alpha (0~255)
  │ switchElevation       Switch elevation
  ├─ 导航 ────────────────────────────────────────────────
  │ navInactive / navSelected   底部导航未选中/选中色
  │ navBadgeColor               导航 badge 背景（0=默认 cyan）
  ├─ 元信息 ──────────────────────────────────────────────
  │ lightPalette          是否浅色皮，驱动状态栏图标反色
  └───────────────────────────────────────────────────────

2.2 调用契约

  Activity / Fragment 必须监听 SettingsState：

      settingsRepository.getSettingsLiveData().observe(this, state -> {
          AppearanceManager.applyPageAppearance(this, getWindow(), root, state);
          applyPalette(AppearanceManager.paletteOf(state));
      });

  applyPalette(palette) 内部把 palette 字段映射到所有静态 TextView、卡片、按钮。
  RecyclerView 子项：在 adapter.onBindViewHolder 内
  AppearanceManager.currentPalette(itemView.getContext()) 应用到子 view。

2.3 添加新主题

  1. ThemePalette 加常量 MY_THEME = myTheme();
  2. forState(state) switch 中登记 chatBackground key。
  3. SettingsRepository / 设置页选项中追加。
  4. 业务代码无需改动 — 全部读 palette 字段，自动生效。

2.4 添加新字段

  1. ThemePalette 增加字段（@ColorInt / @DrawableRes 标注）。
  2. 8 个 palette 工厂各补一行赋值（编译器不强制，靠人工 review）。
  3. 业务代码读 palette.newField。

3. 页面骨架
================================================================================

3.1 通用骨架（顶栏 + 内容 + 底栏）

  ┌───────────────────────────────────────┐
  │ 系统状态栏（WindowInsets，运行时计算）│
  ├───────────────────────────────────────┤
  │ MaterialToolbar  (app_bar_height)     │
  ├───────────────────────────────────────┤
  │ 内容区                                 │
  │   paddingHorizontal: page_horizontal_padding │
  │   paddingTop:        page_top_spacing │
  │   paddingBottom:     page_bottom_content_padding │
  │   maxWidth:          content_max_width │
  ├───────────────────────────────────────┤
  │ BottomNavigationView (bottom_tab_height) │
  └───────────────────────────────────────┘

3.2 滚动 + 键盘

  - 表单页根布局必须包 NestedScrollView，避免键盘遮挡按钮。
  - AndroidManifest 给登录/注册 activity 加 windowSoftInputMode="adjustResize"。
  - 长列表用 RecyclerView，绝不嵌入 NestedScrollView 中（否则失去回收）。

3.3 响应式（sw600dp）

  - dimens.xml + values-sw600dp/dimens.xml 提供两套关键 token。
  - 内容容器加 layout_constraintWidth_max="@dimen/content_max_width"，
    宽屏不会撑满，保持阅读舒适。
  - 横屏聊天双栏（左会话列表 + 右会话）暂未实现，作为后续扩展。

4. 组件规范
================================================================================

4.1 卡片  (MaterialCardView)

  - 圆角           card_radius (16dp)
  - 内边距         card_inner_padding (16dp)
  - 描边色         palette.cardStroke
  - 背景           palette.bgGlassCard / bgListCard
  - elevation      玻璃感卡片为 0；实体卡片可用 card_elevation
  - 卡片间距       垂直 space_md

4.2 按钮  (MaterialButton)

  | 类型     | height                  | corner                  | 触发反馈        |
  |----------|-------------------------|-------------------------|-----------------|
  | 主按钮   | button_primary_height   | button_primary_corner   | CONFIRM         |
  | 次按钮   | button_secondary_height | button_secondary_corner | KEYBOARD_TAP    |
  | 小按钮   | button_small_height     | button_small_corner     | KEYBOARD_TAP    |
  | 图标按钮 | button_icon_size        | 圆形                    | KEYBOARD_TAP    |

  - 主按钮渐变 drawable（如 bg_button_gradient_20）默认蝴蝶蓝；
    后续可在 palette 加 bgPrimaryButton 字段实现按主题切换。
  - 失败抖动：playButtonPress() ObjectAnimator scale 0.95 → 1.0  150ms。

4.3 输入框  (TextInputLayout + TextInputEditText)

  - 高度            input_min_height
  - 圆角            input_corner_radius
  - boxBackgroundMode  outline
  - boxBackgroundColor Color.TRANSPARENT  ← 让父卡片背景透出
  - boxStrokeColor     palette.cardStroke
  - hintTextColor      palette.textTertiary
  - EditText textColor palette.textPrimary
  - **错误**：til.setError("...") + EditText.requestFocus()，禁止 Toast
  - **清错**：在 EditText.addTextChangedListener 内 til.setError(null)

4.4 列表项

  - 高度按内容档位选 list_item_single/double/triple_height
  - 横向 padding    space_md
  - 头像-文本间距   space_sm
  - 列表分隔由背景 drawable 自带（圆角 + stroke），不要再加 divider

4.5 消息气泡

  - 圆角        bubble_corner（不对称：靠头像侧顶角实角，体现指向性）
  - 内边距      bubble_padding
  - 最大宽度    user 280 / receive 300
  - 头像        avatar_md
  - 气泡-头像间距  space_sm
  - 气泡背景由主题 drawable 决定（chat 列表自动按 chatBackground 切换）

4.6 头像

  - 4 档（avatar_sm/md/lg/xl，§1.7）
  - 圆形：MaterialCardView + cardCornerRadius=size/2，或 ShapeableImageView
  - 占位：@mipmap/tubiao（默认头像）

4.7 弹窗

  - 圆角       dialog_corner
  - 边距       dialog_padding
  - 标题       18sp、palette.textPrimary
  - 内容       14sp、palette.textSecondary
  - 主+次按钮间距 space_md
  - 已 token 化：dialog_add_friend / dialog_change_password / dialog_edit_profile /
                dialog_settings_choice / dialog_settings_confirm

6. 状态设计
================================================================================

6.1 加载

  - 全屏加载    透明遮罩 + ProgressBar (indeterminateTintList = palette.textPrimary)
  - 按钮加载    btn.setEnabled(false) + 文案改"登录中..."
  - 列表加载    item 占位骨架（暂未实现，可作为后续扩展）

6.2 空态

  - RecyclerView 上方覆盖 emptyView（同一 ConstraintLayout 内）
  - 居中：图标（avatar_xl 大小灰度）+ 14sp 提示语 (palette.textSecondary)
  - 类型：空联系人 / 空会话 / 无搜索结果 / 空黑名单

6.3 错误

  - **表单字段错误**       til.setError(...)（不要 Toast / Snackbar）
  - **网络错误**           Snackbar，提供"重试"动作（顶端、palette 背景）
  - **致命错误**           AlertDialog（dialog_corner / dialog_padding）
  - 错误文案规则：
      - 中文优先，控制在 12 字以内
      - 描述"是什么不对"，不解释技术细节
      - 给可执行动作（"请输入扣扣号"而不是"账号不能为空"）

6.4 成功反馈

  - 轻量    Snackbar 1.5s（默认 SHORT）
  - 强反馈  HapticFeedback.CONFIRM + Snackbar
  - 跳转前  postDelayed(180~200ms) 让用户看到反馈再切屏

7. 动效预算
================================================================================

7.1 时长

  | 场景            | 时长     | 备注                  |
  |-----------------|----------|-----------------------|
  | 微反馈          | 75-150ms | 按下/松开缩放         |
  | 局部组件切换    | 220ms    | 卡片 fade+slide       |
  | 页面入场        | 300-400ms| logo/hero 淡入        |
  | 长动画上限      | ≤ 500ms  | 超过应当拆分          |

7.2 缓动

  - 入场    DecelerateInterpolator
  - 出场    AccelerateInterpolator
  - 标准    FastOutSlowInInterpolator（Material 默认）

7.3 触觉反馈（HapticFeedbackConstants）

  - 主按钮点击    CONFIRM
  - 次按钮/链接   KEYBOARD_TAP
  - 长按删除      LONG_PRESS
  - 拖拽吸附      GESTURE_END

7.4 动画属性

  - 推荐     translation / scale / rotation / alpha （不触发 layout）
  - 禁止     每帧 invalidate + 重新 measure / layout
  - 装饰特效见 §9 性能铁律

================================================================================
8. 可访问性
================================================================================

8.1 触控目标

  最小 48×48dp（含 padding）。所有图标按钮已用 button_icon_size。

8.2 字号缩放

  SettingsState.fontSize = small/medium/large
  → AppearanceManager.fontScale = 0.9 / 1.0 / 1.12
  在 applyPageAppearance 内通过 tag 缓存自动应用到 RecyclerView 子项。
  **禁止用 dp/px 设置文字尺寸，必须 sp**。

8.3 对比度

  - 浅色主题（minimal_white / pink_bunny）：palette.textPrimary 与背景 ≥ 4.5:1
  - 深色主题：≥ 7.0:1（推荐）
  - 切到浅色主题不能"白底白字" — 所有静态文字必须走 palette，
    不能仅依赖 @color/butterfly_text_*（那是深色主题专用 fallback）。

8.4 contentDescription

  纯图标按钮必须带 android:contentDescription（已在 activity_chat 等执行）。

================================================================================
9. 性能与禁忌  （与 扩展.md §9.5 联动）
================================================================================

铁律 1： **永远不要 setLayerType(LAYER_TYPE_SOFTWARE, null)**
  软件层让整 View 走 CPU 路径，是主题卡顿的根因。
  替代方案：发光 → 多层同心圆；模糊 → 多次偏移 drawText。

铁律 2： **永远不要 setShadowLayer / BlurMaskFilter**
  低端机帧率下崩坏。
  替代方案：自绘多层 stroke / 4 方向偏移补绘。

铁律 3： **帧调度用 postInvalidateOnAnimation()，不要 postInvalidateDelayed(N)**
  前者与 Choreographer/vsync 对齐，自动适配 60/90/120Hz。

铁律 4： **热路径里不要 Color.parseColor(String) / new RectF() / String.valueOf(char)**
  预解析为 int 字段；类字段级 RectF / Path 复用；char[1] + drawText(char[]...)。

铁律 5： **避免 ConstraintLayout 嵌套 ConstraintLayout**
  一个页面一个 root ConstraintLayout，子项用 LinearLayout / FrameLayout。

铁律 6： **列表必须复用**
  DiffUtil 差分；setHasFixedSize(true)；setRecycledViewPool 共享。

铁律 7： **装饰特效必须 GONE 而不是 INVISIBLE**
  GONE 不参与 measure/layout；INVISIBLE 仍占布局 + 仍 draw。

铁律 8： **重物理（碰撞、网格哈希）放独立 HandlerThread**
  主线程只 postInvalidateOnAnimation + onDraw。

10. 维护流程
================================================================================

10.1 新增/修改组件

  1. dimens.xml 加 token（如 emoji_panel_height）。
  2. 本规范 §1 表中登记。
  3. 业务 XML 引用 @dimen/token。
  4. 若涉颜色：ThemePalette 加字段 + 8 个工厂方法补值。
  5. observeAppearance 中应用到具体 View。
  6. 同步更新 扩展.md。

10.2 新增页面

  1. 选骨架（§3.1 通用 / §3.2 表单滚动 / §3.3 响应式）。
  2. 列表项选高度（§1.6）。
  3. 卡片用 §4.1，按钮用 §4.2，输入用 §4.3。
  4. 接入 ThemePalette（§2.2）。
  5. 错误用 §6.3 内联模式，反馈用 §6.4 Snackbar。
  6. 走 §9 性能铁律 self-check。

10.3 反向追溯

  发现 XML 出现裸 dp 或 #RRGGBB？
  → 优先迁移到 token / palette；
  → 不能立即迁移的写到 扩展.md 待办列表，注明原因。
